## 📂 Estructura del Repositorio

En este espacio encontrarás evidencias concretas de mi trabajo metodológico en el aseguramiento de la calidad de software:

| Carpeta / Directorio | Descripción del Contenido |
| :--- | :--- |
| **`Test-Cases/`** | Casos de prueba detallados (pasos, datos de entrada, resultados esperados) para flujos web y móviles. |
| **`Bug-Reports/`** | Reportes de errores profesionales documentados (pasos para reproducir, severidad, prioridad y evidencias). |
| **`Checklists/`** | Listas de verificación para pruebas exploratorias, de usabilidad y regresión. |
| **`API-Testing/`** | Colecciones y documentación de pruebas de endpoints utilizando Postman. |

## 🚀 Proyectos Destacados

### 1. Urban Routes — Pruebas End-to-End (UI & Funcionales)
* **Objetivo:** Validación integral de los flujos críticos de la interfaz de usuario de la plataforma de movilidad *Urban Routes* (reserva de viajes, selección de tarifas y asignación de parámetros).
* **Artefactos:** Casos de prueba funcionales, checklists de verificación visual y reportes de incidencias detectadas durante la ejecución.

### 2. Urban Grocers — Validación y Pruebas de API (Backend)
* **Objetivo:** Verificación del comportamiento del servidor y endpoints HTTP para la creación de kits de usuario en *Urban Grocers*.
* **Artefactos:** Colecciones de pruebas en Postman, validación de esquemas de respuesta y análisis de códigos de estado.
